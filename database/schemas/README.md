# AMReX Parameter Schemas

Generated by `database/scripts/build_schema.py` (Input Writer: Schema Scraper).

## Files

Each JSON file contains the complete parameter schema for one solver version:

- `pelec_schema_<commit>.json` - PeleC parameters
- `warpx_schema_<commit>.json` - WarpX parameters
- `erf_schema_<commit>.json` - ERF parameters

## Usage

Runtime services load these schemas to create dynamic Pydantic models:

```python
from src.services.config_model_factory import ConfigModelFactory
import json

# Load schema
with open("database/schemas/pelec_schema_abc123.json") as f:
    schema = json.load(f)

# Create Pydantic model
AMReXConfig = ConfigModelFactory.create_from_schema(
    schema, 
    build_config={"USE_EB": "TRUE", "DIM": "3"}
)

# Validate inputs
config = ConfigModelFactory.hydrate(AMReXConfig, inputs_text)
```

## Generation

```bash
# Generate schema for PeleC
python database/scripts/build_schema.py ~/repos/PeleC --solver pelec

# Generate for WarpX
python database/scripts/build_schema.py ~/repos/WarpX --solver warpx

# Auto-detect solver name from repo path
python database/scripts/build_schema.py ~/repos/PeleC
```
