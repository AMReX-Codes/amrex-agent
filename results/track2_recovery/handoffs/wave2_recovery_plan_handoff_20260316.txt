## Implementation Plan

### 1. Reviewer failure taxonomy + structured reflexive guidance
1. Add generic reason codes in base config: intent_missing, solver_mismatch, baseline_path_mismatch, domain_conflict, schema_unresolved, resource_conflict, rate_limit_pressure.
2. Extend reviewer result payload with constraints:
   required_solver, forbidden_path_patterns, preferred_path_patterns, excluded_cases, schema_escalation_required, replan_reason_codes.
3. Architect consumes this payload before reselection/replan.

### 2. Clarification vs correctness retry routing
1. Clarification only when taxonomy includes intent_missing.
2. All correctness failures route reviewer -> architect retry with constraints.
3. Implement in current runtime graph path (create_amrex_agent_graph) via router changes; no immediate graph-builder migration required.

### 3. Reviewer-gated schema escalation (429 mitigation)
1. Default policy: lightweight prompt/heuristic parameter pass first.
2. Full schema-heavy pass only when reviewer flags necessity (schema_escalation_required=true) or unresolved/unsafe parameters persist.
3. Forward adaptation of existing logic (no rollback): reuse _needs_schema_fallback decision space and current input-writer schema handling.

### 4. General guardrails + solver-config overrides
1. Keep policy defaults in base config.
2. Keep solver-specific metadata in *_config.py.
3. Reviewer checks solver/path/intent consistency generically, then emits constraints.

### 5. Auditability hardening
1. Add run_manifest.json in each probe root: CLI, checksums (prompt/config), git SHA/dirty, FAISS provenance digest, timestamps.
2. Add per-row hierarchical_candidates.json top-N artifact with ranking breakdown.
3. Keep compact workflow history pointer to detailed artifacts.

### 6. Final handoff artifact generation
1. Produce a new handoff file containing the chronology above plus implementation tasks, acceptance criteria, and rollout decisions.
2. Explicitly include "why 100-row-era context still matters" and "why extra pre-fix runs were not expanded."
